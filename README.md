# 广告公司模拟器

## 在线试玩

**[点这里直接开始玩](https://zhaohongliu86-netizen.github.io/agency-cashflow-game/)**

一直想知道，如果真的经营一家广告公司，自己会是什么样的老板。

所以我做了这个小游戏。

你会遇到老客户、Pitch、年框、Free、招人、涨薪、年终奖、年会、员工离职、现金流和税。有人想做一家小而美的公司，有人一路招人抢大单，也有人可能经营到一半发现：广告公司最难的不是赢稿，是活下来。

我的初衷其实很简单：

**我想自己感受一下广告公司的模拟经营。**

也请大家来感受感受。

看看三年以后，你的公司还在不在，赚了多少钱，以及最后，你会成为一个什么样的广告公司老板。

## 怎么玩

游戏时间约 5～8 分钟。

你需要经营一家广告公司 3 年，在有限的人力和现金里决定：

- 接什么生意
- 要不要 Pitch
- 要不要用 Free
- 什么时候招人
- 要不要扩大公司规模
- 年终奖发多少
- 年会办不办
- 现金不够时，是继续撑，还是宣布破产

不同经营方式都有自己的代价，没有唯一正确路线。

## 当前机制

- 2006 / 2016 / 2026 三种开局难度
- 老客户、散活、年框、Pitch 等不同业务类型
- Pitch 有基础胜率，也可以额外投入人力和成本
- 连续赢 Pitch 可能带来连带项目
- 连续输 Pitch 可能引发员工离职
- 招聘需要成本，新员工不会立刻到岗
- 每年默认涨薪
- 年终奖和年会会影响团队状态
- 公司规模越大，才有机会解锁更大的项目
- 允许负现金硬撑，也可以主动破产
- 三年结束后，会根据你的经营方式给出一个老板类型

## 本地运行

这是一个纯前端小游戏，不需要数据库。

直接打开 `index.html` 即可运行。

也可以在项目目录下运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 关于这个项目

这是一个还在持续迭代的小实验。

很多机制来自真实广告公司里熟悉的事情，但它首先是游戏，不是经营教材，也不试图精确模拟所有公司的财务模型。

如果你也是广告人，欢迎玩完以后告诉我：

**你最后活成了什么老板。**
